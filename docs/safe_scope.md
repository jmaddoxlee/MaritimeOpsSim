# MaritimeOpsSim Safe Scope

## Purpose

MaritimeOpsSim is a safe software engineering portfolio project focused on simulated maritime search-and-rescue, maritime domain awareness, vessel telemetry, mission monitoring, command-dashboard visualization, automated testing, and distributed system reliability.

The project is designed to demonstrate practical software engineering skills in C++, C#/.NET, React/TypeScript, Python, networking, telemetry processing, databases, Docker, CI/CD, and system design.

---

## Allowed Scope

The project may include:

- Search-and-rescue simulation
- Maritime domain awareness
- Distress beacon response
- Vessel telemetry generation
- Fleet simulation
- Mission monitoring
- Command-dashboard visualization
- Communication loss simulation
- Low-fuel alerts
- Stale telemetry detection
- Restricted-zone warnings
- Packet loss simulation
- Corrupt packet handling
- Backend fault tolerance
- Time-series telemetry storage
- Automated integration testing
- Python-based chaos testing
- Software engineering education

---

## Not Allowed Scope

The project shall not include:

- Weapon targeting
- Missile guidance
- Strike planning
- Combat engagement
- Fire-control logic
- Attack optimization
- Enemy engagement
- Lethality modeling
- Real-world tactical recommendations
- Real autonomous vessel control
- Real vessel command execution
- Real-world operational decision support

---

## Public Description

The project should be described publicly as one of the following:

- Distributed maritime telemetry platform
- Command-and-telemetry platform
- Mission monitoring platform
- Search-and-rescue simulation platform
- Maritime domain awareness simulation
- Real-time telemetry dashboard project

Avoid describing the project as:

- Weapon system
- Combat system
- Targeting platform
- Fire-control system
- Real tactical command system

---

## Safety Boundary Statement

MaritimeOpsSim is designed only for safe search-and-rescue simulation, maritime domain awareness, telemetry analysis, mission monitoring, automated testing, and software engineering education.

The system does not include weapon targeting, missile guidance, fire-control logic, strike planning, attack optimization, enemy engagement, or real-world tactical recommendations.
